Under the hood

  • Integrity SHA-512 verified against npm registry metadata. Registry host is pinned — tarballs can't be swapped in transit.
  • Versioning Semver ranges and a lockfile. Pin exact versions or accept patch updates — same model as ESLint configs.
  • Multi-platform One source of truth, synced simultaneously to Cursor, Claude Code, GitHub Copilot, and Windsurf.
  • Profiles Role-matched defaults — frontend, backend, devops, agentic. Pre-selected, not locked. Add or remove anything.
