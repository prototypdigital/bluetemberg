# Installation

Bluetemberg is published on the public npm registry as [`bluetemberg`](https://www.npmjs.com/package/bluetemberg) (MIT licensed). No authentication or registry configuration is required.

## Prerequisites

- Node.js >= 18
- npm, pnpm, or yarn

## Install

### Option A: Run directly with npx

```bash
npx bluetemberg init
```

### Option B: Install as a dev dependency

```bash
npm install -D bluetemberg
# or
pnpm add -D bluetemberg
```

Then use via package scripts:

```bash
npx bluetemberg init
npx bluetemberg sync
```
